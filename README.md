# Eye Tracking Demo

A single-page eye tracking demo for GitHub Pages. It uses [WebGazer.js](https://webgazer.cs.brown.edu/) to estimate where you are looking on the page, then shows a live indicator and activity log for the region beneath your gaze.

## Usage

1. Open the deployed page and allow camera access when prompted.
2. Click **Start tracking**.
3. Move your eyes between the content cards. The glowing cursor follows your gaze and the log records which section you view.
4. Click **Stop** to pause tracking.

All processing happens locally in your browser; refreshing the page clears the log and calibration.
