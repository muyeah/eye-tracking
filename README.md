# 眼球追蹤 GitHub Pages

使用 [WebGazer](https://webgazer.cs.brown.edu/) 在瀏覽器端推測使用者注視的位置，並在畫面上留下時間標記與紀錄的靜態網頁，可部署於 GitHub Pages。

## 功能
- 按下「開始追蹤」後請求鏡頭權限，取得使用者視線推測座標。
- 以半透明光點即時標出目前注視位置，每秒在畫面與紀錄欄位新增一次時間標記。
- 畫面上的標記約 5 秒後自動淡出，紀錄欄位最多保留 20 筆最新資料。
- 所有影像資料皆僅在瀏覽器端處理，不會上傳至伺服器。

## 本機預覽
1. 安裝相機並確保瀏覽器有權限。
2. 啟動本機伺服器（任選一種）：
   ```bash
   python -m http.server 8000
   ```
   然後在瀏覽器開啟 http://localhost:8000。

## 部署
本專案是純靜態頁面，可直接推送到 GitHub Pages。確保 `index.html` 位於發佈根目錄即可。
