# 眼球追蹤 GitHub Pages

這個專案是一個前端單頁應用程式，使用 [WebGazer.js](https://webgazer.cs.brown.edu/) 在瀏覽器端估算使用者的視線，並以光圈與紀錄面板即時顯示注視位置。

## 功能
- 透過「開始追蹤」啟用攝影機並啟動視線估計。
- 在畫面中以光圈標示目前的注視點，並在底部顯示座標與可信度。
- 透過熱度光暈疊加呈現歷史視線軌跡。
- 「暫停」可停止追蹤並清除紀錄。

## 使用方式
1. 開啟 `index.html`（可部署至 GitHub Pages）。
2. 點擊「開始追蹤」，依瀏覽器提示允許攝影機權限。
3. 保持臉部在鏡頭範圍內，觀察頁面內容，底部紀錄會即時更新。
4. 需要停止時點擊「暫停」。

所有運算都在本地瀏覽器完成，不會將影像或視線資料送往伺服器。
